================================================================================
2. TYPOGRAPHY HIERARCHY
================================================================================
Font Family: Inter / Outfit / Poppins / SF Pro Display
- Display / Hero Figures: 32px - 36px | Bold (700/800) | Letter Spacing: -0.5px
- Page Headers:           22px - 26px | Semi-Bold (600)
- Section Titles:         16px - 18px | Medium (500/600)
- Body Text:              14px | Regular (400) | Line Height: 22px
- Captions & Tags:        11px - 12px | Semi-Bold (600) | Uppercase Tracked +1.5px

================================================================================
3. UI COMPONENTS & GLASSMORPHISM GUIDELINES
================================================================================
- Cards: Minimum 20px border radius, 1px frosted gradient stroke, soft drop shadow.
- Action Pills: Circular / Capsule shape (radius: 9999px), micro-icon + label.
- Inputs: 54px height, floating labels, clean prefix (+91 / INR ₹), focused cyan glow.
- Animations: Fluid 60fps springs, fade-slide entries, bottom-to-top exits.
- No Clutter: Remove unnecessary text disclaimers, multi-layered redundant borders,
  or outdated biometric buttons. Keep interfaces focused, fast, and high-conversion.

4. SCREEN-BY-SCREEN LAYOUT & UX ARCHITECTURE
================================================================================

--------------------------------------------------------------------------------
4.1. ANIMATED SPLASH SCREEN
--------------------------------------------------------------------------------
- Background: Midnight Obsidian (#080D1A) with two subtle pulsating radial glow orbs.
- Center Stage:
  * Brand Logo inside a floating glowing capsule.
  * Expanding dual halo pulse rings (cyan/blue).
  * "Anusha Trade" typography with glowing subtitle: "SMART INVESTMENTS & SECURE RETURNS".
  * Verified Badge: "🔒 Bank-Grade 256-Bit Security".
- Exit Transition: Smooth fluid upward glide (-80px translateY + fade) directly into Login.

--------------------------------------------------------------------------------
4.2. SECURE LOGIN SCREEN
--------------------------------------------------------------------------------
- Header: Brand logo with "Welcome Back" greeting and quick tagline.
- Main Form Card (Frosted Glass):
  * Mobile Number input field with fixed "+91" prefix & phone icon.
  * 4-Digit MPIN field with password visibility toggle & numeric keypad.
  * Inline "Forgot MPIN?" link aligned right above the button.
  * Primary Action: "Sign In to Dashboard" vibrant gradient button with loading spinner.
- Footer:
  * "Don't have an account? Create Account" high-contrast link.

--------------------------------------------------------------------------------
4.3. 6-STEP REGISTRATION & KYC FLOW
--------------------------------------------------------------------------------
- Header: Back button, Step Progress Pill (e.g. "STEP 1 OF 6"), and animated progress rail.
- Step 1: Mobile Number Entry -> Automatic 6-digit OTP delivery (with backend fallback).
- Step 2: Full Name & Email Address.
- Step 3: Set 4-Digit MPIN & Security Password.
- Step 4: Referral Code (Optional with instant sponsor lookup preview).
- Step 5: KYC Verification (Aadhaar, PAN upload via Native System Picker, Face photo).
- Step 6: Bank Account Linkage (Account Number, IFSC, Bank Name).
- Final: "Account Created Successfully" confetti animation -> Direct redirect to Dashboard.

--------------------------------------------------------------------------------
